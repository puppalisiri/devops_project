\# Telangana Tourism Blog System



\## Overview



The Telangana Tourism Blog System is a full-stack web application developed to promote tourism destinations across Telangana through an interactive blogging platform. The application allows users to explore famous tourist places, read travel experiences, and share tourism-related blogs with detailed descriptions and images.



The platform is designed to provide a user-friendly and visually appealing environment where visitors can discover the cultural heritage, historical monuments, temples, waterfalls, wildlife destinations, and tourist attractions of Telangana. The system also enables administrators to manage tourism content efficiently through a dedicated admin dashboard.



This project is developed using Node.js, Express.js, MySQL, EJS, Bootstrap, HTML, CSS, and JavaScript. It follows a dynamic web application architecture where the frontend is connected with a MySQL database using Express.js backend services.



\---



\# Objectives of the Project



\- To promote tourism destinations of Telangana digitally.

\- To develop a responsive and user-friendly tourism management system.

\- To implement authentication and authorization using Node.js and Express.js.

\- To manage tourism content dynamically using MySQL database integration.

\- To enhance user interaction using comments, likes, image uploads, and search functionality.

\# Working of the System



1\. Users can register and log in to the platform.

2\. Logged-in users can add tourism blogs with images and descriptions.

3\. Users can explore tourism blogs by district or category.

4\. Visitors can search tourism places dynamically.

5\. Users can interact with blogs through comments and likes.

6\. Admin can securely log in through the Admin Login page.

7\. Admin can manage blogs, users, and tourism content through the dashboard.
